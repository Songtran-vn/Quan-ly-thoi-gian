Đồng bộ Google Sheets
Hướng dẫn thiết lập Google Sheets

Làm theo 4 bước dưới đây để tạo Google Sheet riêng và kết nối với app.

1
Tạo Google Sheet mới
Truy cập sheets.google.com → Click "Trống" để tạo sheet mới. Để trống hoàn toàn, app sẽ tự điền dữ liệu vào.
Lưu ý: Không cần thay đổi gì trong sheet.
2
Mở Apps Script
Trong Google Sheet → Click menu "Tiện ích mở rộng" → Chọn "Apps Script". Một tab mới sẽ mở ra với editor code.
3
Paste code vào Apps Script
Xóa toàn bộ code cũ → Paste code bên dưới vào → Click 💾 Save.
// Work Atelier — Apps Script function doPost(e) { try { var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0]; var body = JSON.parse(e.postData.contents); body.rows.forEach(function(row){ sheet.appendRow(row); }); return ContentService .createTextOutput(JSON.stringify({success:true})) .setMimeType(ContentService.MimeType.JSON); } catch(err) { return ContentService .createTextOutput(JSON.stringify({error:err.message})) .setMimeType(ContentService.MimeType.JSON); } }
4
Deploy và lấy URL
1. Click "Deploy" → "New deployment"
2. Click ⚙ bánh răng → chọn "Web app"
3. Execute as: Me · Who has access: Anyone
4. Click "Deploy" → cấp quyền → Copy URL
Sau đó: Dán URL vào tab "Đồng bộ Google Sheets" → nhấn "Lưu lên Google Sheets" để kiểm tra.
Xóa tất cả công việc?
Toàn bộ danh sách sẽ bị xóa khỏi app.
Dữ liệu đã lưu lên Google Sheets không bị ảnh hưởng.
