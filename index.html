Đồng bộ Google Sheets
Hướng dẫn thiết lập Google Sheets

Làm theo 4 bước dưới đây để tạo Google Sheet riêng và kết nối với app.

1
Tạo Google Sheet mới
Truy cập sheets.google.com → Click "Trống" để tạo sheet mới.
Sheet đầu tiên (tab dưới cùng) giữ nguyên tên mặc định, hoặc đổi tên tùy ý — sẽ dùng ở bước sau.
Lưu ý: Không cần thay đổi gì trong sheet, để trống hoàn toàn. App sẽ tự điền dữ liệu vào.
2
Mở Apps Script trong Sheet
Trong Google Sheet vừa tạo → Click menu "Tiện ích mở rộng" (Extensions) → Chọn "Apps Script".
Một tab mới sẽ mở ra với editor code.
3
Paste code vào Apps Script
Xóa toàn bộ code cũ trong editor → Paste đoạn code bên dưới vào → Click 💾 Save.
// Work Atelier — Apps Script function doPost(e) { try { var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0]; var raw = e.postData.contents; var body = JSON.parse(raw); var rows = body.rows; for (var i = 0; i < rows.length; i++) { sheet.appendRow(rows[i]); } return ContentService .createTextOutput(JSON.stringify({success: true})) .setMimeType(ContentService.MimeType.JSON); } catch(err) { return ContentService .createTextOutput(JSON.stringify({error: err.message})) .setMimeType(ContentService.MimeType.JSON); } }
4
Deploy và lấy URL
1. Click "Deploy" (góc trên phải) → "New deployment"
2. Click biểu tượng ⚙ bánh răng → Chọn "Web app"
3. Điền thông tin:
  • Execute as: Me
  • Who has access: Anyone
4. Click "Deploy" → Google sẽ hỏi cấp quyền → Click "Authorize" → "Allow"
5. Copy URL hiện ra (dạng https://script.google.com/macros/s/.../exec)
Quan trọng: Dán URL vừa copy vào tab "Đồng bộ Google Sheets" của app, rồi nhấn "Lưu lên Google Sheets" để kiểm tra kết nối.
